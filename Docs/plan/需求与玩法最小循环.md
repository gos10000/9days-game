## 1. 一句话玩法

双方角色回合制对射：每回合先抽选道具或子弹，选道具则先在网格上搭建力场，再把子弹打出去；子弹受场上道具的引力/斥力/重力影响改变轨迹；打到对方扣血，一方血量归零即分出胜负。

---

## 2. 回合制核心流程

```
A 回合前（抽选道具/子弹）
   → A 回合中（摆放道具，仅当选道具时）
   → 发射子弹
   → A 回合后（等待子弹反馈）
   → B 回合前
   → 循环

### 2.1 回合前 · 抽选

| 步骤 | 说明 |
|---|---|
| 先手判定 | 随机决定先手，视角锁定先手角色 |
| 抽取界面 | 从子弹与道具混合池中**抽取 4 样物品**并展示 |
| 选择 | 玩家选定其中 1 样后，界面消失 |
| 分支 | 选到**道具** → 进入搭建板块；选到**子弹** → 跳过搭建，直接进入发射环节 |

### 2.2 回合中 · 搭建（仅选道具时）

- 视角缩小至全图
- 在**网格**中搭建道具（参考《超级鸡马》的搭建环节）
- 交互：**左键放置**，**右键取消放置**
- 放置时必须能看到该道具的作用范围（例：黑洞的引力范围）
- 全部放置完成后，点击**完成按钮**结束搭建，界面消失

### 2.3 发射环节

- 视角回正
- 拖动调整角度与力度（手感参考《愤怒的小鸟》：鼠标向后拖，子弹向前飞，拖得越长初速度越大）
- 屏幕上同时显示：
  - 一小段**预计弹道**
  - 一整段**历史弹道**（如果存在上一发记录）
- 确定方向与力度后发射

### 2.4 子弹飞行与击中

| 环节 | 表现 |
|---|---|
| 镜头 | 发射后跟随子弹，建议加**镜头死区**，避免画面过晃 |
| 击中 | 轻微视角抖动 + 角色受击闪白 |
| 冲击 | 子弹爆炸产生轻微冲击，导致目标位置偏移；可做搞怪效果（人物手脚胡乱摆动） |
| 顿帧 | 击中瞬间增加顿帧以提升打击感（工期允许） |
| 结算 | 镜头在击中位置**停留 2 秒**，然后切至另一方，进入其回合 |
| 地形破坏 | 看工期决定是否实现（非必要） |

### 2.5 胜负

- 重复上述流程，直到**一方血量归零**
- **（非必要）** 胜利后视角锁定败者的死状，屏幕下方弹出嘲讽界面，点击按钮会在屏幕上生成嘲讽弹幕

## 3. 程序模块清单

| 模块 | 需求 | 备注 |
|---|---|---|
| 回合制 | 完成 `A回合前 → A回合中 → 发射 → A回合后 → B回合前` 的循环 | 核心骨架 |
| 摄像头跟随 | A 回合时镜头在 A；发射瞬间镜头微微偏向发射方向（优化手感，非必要）；发射后跟随子弹；击中后停留 2–3s，再切至 B | 建议加镜头死区 |
| 抽取与选择逻辑 | 回合前完成抽取并选择道具与子弹 | 抽取池构成见「待确认」 |
| 道具搭建逻辑 | 回合中摆放道具；摆放时能看到所有道具的作用范围 | 网格化，左键放置/右键取消 |
| 道具逻辑 | 各道具的力场/重力/障碍效果正确作用 | 见第 5 节 |
| 角色受击 | 屏幕略微振动 + 角色闪白 | 振动是否含 HUD 需确认 |
| 子弹发射逻辑 | 发射前显示一小段轨迹；愤怒的小鸟式拖拽发射；显示上一发完整轨迹 | 见第 6 节 |
| 场景搭建 | 主菜单、对战场景、暂停界面 | 主菜单由另一人负责 |
| 获胜阶段（非必要） | 镜头切至败者，点击按钮发嘲讽弹幕 | |
| 地形破坏逻辑（非必要） | 地形可被破坏 | |

## 5. 道具一览

全部为**常驻**单位，放置后在场上持续生效。

| 道具 | 效果 | 范围 |
|---|---|---|
| 黑洞 | 引力单位，可略微改变子弹轨迹 | 圆形 |
| 强力黑洞 | 引力单位，可极大改变子弹轨迹 | 圆形 |
| 白洞 | 斥力单位，可略微改变子弹轨迹 | 圆形 |
| 强力白洞 | 斥力单位，可极大改变子弹轨迹 | 圆形 |
| 重力反转场 | 区域内重力方向改变；需摆放在地面 | 其上方区域 |
| 重力加重场 | 区域内重力加大；需摆放在地面 | 其上方区域 |
| 反重力障碍 | 障碍物，可无视重力随意摆放 | 单体（体型较小） |

## 6. 子弹一览

| 子弹 | 效果 | 特殊说明 |
|---|---|---|
| 普通子弹 | 带一定爆炸范围 | 轨迹不可控，避免双方都打不中 |
| 爆破子弹 | 爆炸范围为普通子弹的 **2 倍** | |
| 拆除子弹 | 拆除沿途道具 | 无视道具重力影响；**无法对对方造成伤害** |
| 强化子弹 | 伤害为普通子弹的 **2 倍** | |
| 引力子弹 | 无视所有道具影响 | 直线/纯物理飞行 |
| 曳光弹 | 可显示完整轨迹 | 用于侦查与校准 |
